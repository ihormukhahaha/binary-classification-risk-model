# Binary Classification Risk Model

## 📌 Опис проєкту
Проєкт присвячений побудові та порівнянню моделей бінарної класифікації для задач ризик-менеджменту. Основна увага приділена обробці дисбалансу класів, розвідувальному аналізу даних (EDA) та оцінці якості за допомогою метрик ROC-AUC.

## 🛠 Використаний стек технологій
- **Python**
- **Pandas, NumPy** — обробка та аналіз даних
- **Scikit-learn** — моделювання (Logistic Regression, Decision Tree, Random Forest)
- **Matplotlib, Seaborn** — візуалізація даних

## 📁 Структура блокнота (`risk_classification.ipynb`)
1. **Завантаження та первинний огляд даних (EDA):** аналіз розмірності, типів даних та розподілу цільової змінної (`gb`).
2. **Попередня обробка (Preprocessing):** розділення вибірки, обробка пропусків, масштабування числових ознак.
3. **Навчання моделей:**
   * Логістична регресія (з урахуванням зважування класів).
   * Дерево рішень та Випадковий ліс.
4. **Оцінка результатів:** порівняння моделей за допомогою класифікаційного звіту та ROC-AUC.
