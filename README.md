# Binary Classification Risk Model

## 📌 Project Overview
This project focuses on building and comparing binary classification models for risk management tasks. Special attention is given to class imbalance handling, exploratory data analysis (EDA), and evaluation using ROC-AUC metrics.

## 🛠 Tech Stack
* **Python**
* **Pandas, NumPy** — Data manipulation and analysis
* **Scikit-learn** — Modeling (Logistic Regression, Decision Tree, Random Forest)
* **Matplotlib, Seaborn** — Data visualization

## 📁 Notebook Structure (`risk_classification.ipynb`)
1. **Exploratory Data Analysis (EDA):** analyzing dataset dimensions, data types, and target variable distribution (`gb`).
2. **Preprocessing:** train-test split, handling missing values, scaling numerical features.
3. **Model Training:**
   * Logistic Regression (with class weighting).
   * Decision Tree and Random Forest classifiers.
4. **Evaluation:** comparing models using classification reports and ROC-AUC scores.
